本目录有算法源文件和两种架构的 L2 静态库，但没有系统镜像、全部 apt 包、完整录包、部署成功记录或新机标定报告。不能据此承诺离线刷机后直接复现。

历史导出基准保留在旧manifest中；本目录已有后续用户提交。2026-10-23核对252个对应常规文件均与原机一致，见实机核查；不代表二进制重建、实际烧录固件或合同功能已通过。部署路径与IP适配应只发生在候选副本；构建、感知、运动和重定位需要分别验收。
