本目录有算法源文件和两种架构的 L2 静态库，但没有系统镜像、全部 apt 包、完整录包、部署成功记录或新机标定报告。不能据此承诺离线刷机后直接复现。

运行代码保持导出基准。部署路径与 IP 适配只发生在 `tools/reproduce.py stage` 的候选副本；构建、感知、运动和重定位需要分别验收。
