# 小车运动控制说明（可直接转发）

> 面向：需要接手调试「网页控制车走」的同学。
> 结论先行：网页上的**前进/后退**和**左转/右转**不是直接控电机，而是走四层链路，任何一层断了车都不动。

---

## 1. 四层链路总览

```
浏览器摇杆
   │  POST /api/ctl/drive   {"v": 0..1, "w": -1..1}
   ▼
console_backend.py  (HTTP 8090)
   │  ROS 话题 /cmd_vel  (geometry_msgs/Twist)
   ▼
chassis_gimbal_bridge.py  (systemd: jiaoda-control)
   │  串口 115200, 20 Hz, 文本帧
   ▼
ESP32-S3 固件 control_1.ino  (/dev/ttyACM0)
   │  PWM 50 Hz, 1000–2000 µs
   ▼
电调 ESC  →  履带电机 / 云台舵机
```

**关键点：网页只是"发速度"，真正把速度变成 PWM 的是 ESP32。**

---

## 2. 每一层的代码位置与参数

### 2.1 网页端（摇杆）

文件：`~/jiaoda/console.html`

| 行 | 内容 |
| --- | --- |
| 207 | 左摇杆 `<div id="joyL">` —— 前进/后退 |
| 208 | 右摇杆 `<div id="joyR">` —— 左转/右转 |
| 371 | `joystick($('#joyL'),(x,y)=>{drv.v=y; ...})` |
| 372 | `joystick($('#joyR'),(x,y)=>{drv.w=-x; ...})` ← **注意这里取负** |
| 373 | `sendDrive()`：80 ms 节流，POST `/api/ctl/drive` |

摇杆的坐标换算在 `function joystick()` 里：`cb(x*2, -y*2)`，所以**往上推 = y 为正 = 前进**。

> ⚠️ **转向反了的头号原因**：旧版本这里是 `drv.w = x`（没取负），右摇杆方向就会反。
> 如果你手上的 `console.html` 是 `drv.w=x`，改成 `drv.w=-x` 再刷新浏览器即可。

### 2.2 后端

文件：`~/jiaoda/console_backend.py`

```python
# 第 109–116 行
def drive(self, v, w):
    m = self.Twist()
    m.linear.x  = float(v) * state["params"]["pspeed"]      # 默认 0.55
    m.angular.z = float(w) * math.radians(state["params"]["pyaw"])  # 默认 40°/s
    self.pub_cmd.publish(m)
```

- `pspeed`（行走速度）默认 **0.55**，网页滑块可改；
- `pyaw`（转向速度）默认 **40 °/s**，网页滑块可改；
- 也就是说网页摇杆满推 → `cmd_vel.linear.x = 0.55 m/s`、`angular.z = 0.70 rad/s`。

### 2.3 串口桥接

文件：`~/jiaoda/chassis_gimbal_bridge.py`（systemd 单元 `jiaoda-control`）

| 行 | 内容 |
| --- | --- |
| 15 | `PORT = os.environ.get("CTL_PORT", "/dev/ttyACM0")` |
| 16 | `BAUD = 115200` |
| 17–18 | `THR_K` / `STR_K`：m/s、rad/s → 整数档位的换算系数 |
| 31–32 | `cmd["t"] = clamp(linear.x * THR_K)`，`cmd["s"] = clamp(angular.z * STR_K)` |
| 83–84 | **看门狗**：0.5 s 没收到新 `/cmd_vel` 就自动清零 |
| 88 | `ser.write("t,s,p,y,chk\n")`，20 Hz |

启动脚本 `~/jiaoda/run_control.sh` 里设了环境变量：

```bash
export THR_K=6.7      # 实测标定后
export STR_K=6.7
export CTL_PORT=/dev/ttyACM0
```

### 2.4 ESP32 固件

文件：`docs/source/firmware/control_1.ino`（Arduino-ESP32 **3.x**）

| 行 | 内容 |
| --- | --- |
| 4–5 | `THROTTLE_PIN 21`、`STEER_PIN 47` |
| 8–9 | `GIMBAL_PITCH_PIN 48`、`GIMBAL_YAW_PIN 45` |
| 36 | `SERIAL_TIMEOUT_MS = 500`（串口断 0.5 s 自动回中位） |
| 87 | `speedToMicroseconds()`：`-30..30` → `1000..2000 µs`，0 → 1500 |
| 128–133 | `setChassisSignal()`：**转向取负** `speedToMicroseconds(-steer)` |
| 241 | 校验：`throttle+steer+pitch+yaw == chk` |

## 3. 串口协议（上下位机唯一接口）

| 项 | 规格 |
| --- | --- |
| 波特率 | 115200 8N1 |
| 频率 | 20 Hz（上位机发） |
| 下行帧 | `"%d,%d,%d,%d,%d\n"` → `throttle,steer,pitch,yaw,checksum` |
| 取值范围 | 每个量 `-30..30` |
| checksum | 四个量直接相加（不取模） |
| 上行 | 启动横幅、`GIMBAL_PULSE:p,y`（每 100 ms）、`Serial T:x S:y ...`（每收到一帧回一行） |

**档位 → PWM 映射**（固件 `speedToMicroseconds`）：

| 档位 | PWM | 含义 |
| --- | --- | --- |
| 0 | 1500 µs | 中位（停） |
| 1..30 | 1600..2000 µs | 正转（递增） |
| -1..-30 | 1400..1000 µs | 反转（递增） |

## 4. 脱离网页，用命令行直接控车

```bash
source /opt/ros/noetic/setup.bash
export ROS_MASTER_URI=http://127.0.0.1:11311

# 前进 0.3 m/s，持续 1 秒
timeout 1 rostopic pub -r 20 /cmd_vel geometry_msgs/Twist '{linear: {x: 0.3}}'
# 立刻停
rostopic pub -1 /cmd_vel geometry_msgs/Twist '{}'

# 看固件有没有收到（每帧都会回显）
rostopic echo /jiaoda/esp_tel | grep Serial
```

判断标准：

- **有 `Serial T:x` 回显** → 串口通了，车应该动；
- **没有回显** → 固件在 RC 模式（遥控器/接收机还插着），串口指令被忽略。

## 5. 故障速查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 网页点了没反应，车不动 | 桥接没起 | `systemctl status jiaoda-control` |
| 车不动，esp_tel 无 `Serial` 回显 | 固件处于 RC 模式 | 拔掉接收机 → **重启 ESP32**（RTS 脉冲） |
| 车不动，桥接日志报 `open /dev/ttyCH343USB0 fail` | 端口名写错 | 改 `CTL_PORT=/dev/ttyACM0` |
| 转向反了 | 右摇杆没取负 | `console.html:372` 改 `drv.w=-x`，刷新页面 |
| 一次重启后车抽一下 | ESP32 靠 Jetson USB 供电，断电瞬间 PWM 消失 | 硬件上给 ESP32 独立 5V |
| 速度比预期快很多 | `THR_K` 与电调非线性 | 实测标定，见下 |

**实测速度曲线**（`THR_K=6.7` 时）：

| cmd_vel | 实际档位 | 实测速度 |
| --- | --- | --- |
| 0.03 m/s | 1（1600 µs） | ≈ 0.26 m/s |
| 0.055 m/s | 3 | ≈ 0.35 m/s |
| 0.11 m/s | 6 | ≈ 0.59 m/s |

> 也就是说：**这台车最低只能跑 0.26 m/s 左右**，再小的指令电调不响应。想更慢必须改固件的低端映射并重新烧录。

## 7. 一句话总结

**网页发速度 → 后端转 `/cmd_vel` → 桥接转串口文本 → ESP32 转 PWM → 电调驱动电机。**
任何一环断（服务没起、串口名错、固件在 RC 模式、方向取反），车就不动或反着走。
